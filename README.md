## How to Study

1. Read the topic notes and predict the example's output.
2. Compile and run the code using the commands in the notes.
3. Answer the interview questions aloud in English.
4. Use the review checklist to identify what needs more practice.

中文提示：先理解和运行例子，再用英文练习面试回答。

## Writing Guidelines

Keep this README as the main guide, linking to every topic. Store topic notes in `interview/<topic>.md` and examples in `scripts/<topic>.cpp`.

Use English for headings, explanations, and interview answers. Add brief Chinese explanations where they help understanding. Practise explaining each topic in English before checking the Chinese notes.
